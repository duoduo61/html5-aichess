##  项目简介

**中国象棋 · AI** 是一款纯前端的 HTML5 象棋游戏。项目使用 **DeepSeek V4.1 Flash** 辅助开发，整体代码结构清晰、轻量，无需后端服务即可运行。玩家可以选择执红先行或执黑后行，与内置 AI 引擎进行对弈。

> 项目从零实现了中国象棋的完整规则逻辑，包括所有棋子的合法走法生成、将军检测、绝杀判定、长将判和等机制。

## ✨ 功能特性

### 🎮 游戏玩法

| 功能              | 说明                             |
| :---------------- | :------------------------------- |
| **人机对战**      | 内置 AI 引擎，支持多深度搜索     |
| **先后手选择**    | 可选择执红（先走）或执黑（后走） |
| **悔棋**          | 支持撤销上一步操作               |
| **重新开始**      | 一键重置对局                     |
| **走子提示**      | 选中棋子后显示所有合法落点       |
| **上一步高亮**    | 标记最近一步的起点和终点         |
| **将军提示**      | 被将军时红圈警示                 |
| **绝杀/和棋判定** | 自动判定胜负与和棋               |
| **长将判和**      | 检测局面重复，三次重复判和       |

### 🎨 界面与交互

- **Canvas 渲染**：棋盘与棋子通过 Canvas 绘制，支持高清屏（DPR 适配）
- **走子动画**：棋子移动带有平滑的缓动动画
- **Toast 提示**：操作反馈以轻量提示框呈现
- **侧边栏**：关于页面以侧滑抽屉形式展示
- **响应式布局**：适配桌面端与移动端
- **翻转棋盘**：执黑时棋盘自动翻转，符合对弈视角

## 🛠️ 技术实现

### 技术栈

| 层次 | 技术                           |
| :--- | :----------------------------- |
| 渲染 | HTML5 Canvas 2D                |
| 逻辑 | 原生 JavaScript (ES6+)         |
| 样式 | 纯 CSS3（Flexbox、动画、渐变） |
| AI   | Negamax + Alpha-Beta 剪枝      |
| 架构 | IIFE 模块化，无构建工具依赖    |

### 核心模块

```
index.html ── 页面结构
style.css  ── 样式与动画
engine.js  ── 象棋规则引擎 + AI 搜索算法
app.js     ── 游戏流程控制 + Canvas 渲染 + 交互
```

## 🤖 AI 引擎说明

AI 引擎位于 `engine.js`，采用经典的 **Negamax 搜索 + Alpha-Beta 剪枝** 算法。

### 搜索流程

```
findBestMove(board, side, maxDepth)
  ├── 生成所有合法走法（genLegalMoves）
  ├── 按吃子价值排序（orderMoves）
  ├── 迭代加深搜索（Iterative Deepening）
  │     └── 每一层：Negamax + Alpha-Beta 剪枝
  └── 返回最优走法
```



### 局面评估

引擎对每个棋子赋予基础分值，并根据棋子的位置进行动态调整：

| 棋子  | 基础分值 | 位置加成                           |
| :---- | :------- | :--------------------------------- |
| 帅/将 | 10000    | —                                  |
| 车    | 900      | 过河后小幅加成                     |
| 炮    | 450      | 中路位置加成                       |
| 马    | 400      | 中路位置加成                       |
| 相/象 | 200      | —                                  |
| 仕/士 | 200      | —                                  |
| 兵/卒 | 100      | 过河后大幅加成，靠近中路有额外加成 |

### 搜索参数

| 参数                | 值         | 说明             |
| :------------------ | :--------- | :--------------- |
| `MAX_DEPTH`         | 3          | 默认搜索深度     |
| `SEARCH_TIME_LIMIT` | 4000ms     | 搜索超时时间     |
| 剪枝策略            | Alpha-Beta | 显著减少搜索节点 |

> 💡 搜索深度可通过修改 `engine.js` 中的 `MAX_DEPTH` 常量调整。深度越大，AI 棋力越强，但计算时间也相应增加。
